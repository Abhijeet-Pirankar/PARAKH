# PARAKH - AI-Powered Job & Internship Offer Verification System

"Verify Before You Trust."

PARAKH is a web-based platform that helps college students, freshers, and job seekers determine whether a job or internship offer is likely genuine or suspicious.

## Project Structure
- `/recruitshield-frontend` - React application (Vite)
- `/backend` - Java Spring Boot REST API
- `/ai-service` - Python AI/ML Service
- `/database` - MySQL initialization scripts

## Development

1. **Frontend**: cd `recruitshield-frontend` and run `npm run dev`
2. **Backend**: cd `backend` and run `./mvnw spring-boot:run`
